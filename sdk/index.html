Your agent framework reads less. Nothing gets lost.

The gascoigne engine as a library. Wrap a tool, point your LLM client at the local proxy, or run the engine inside your own process, and the model reads a shortened result. The original stays one raw call away.

Other languages: install table. Looking for the command-line tool? gascoigne for agents.

What the model reads

A tool returns a noisy log of about 400 lines. The SDK folds the repeats, keeps the one error and tells the model where the original is. This is the example from the SDK README.

  • 12,025 → 142tokens, the noisy log below
  • 6languages, one surface
  • 4ways to hook in
  • 15framework demos
  • Never throws into your app. Any failure returns the input unchanged, and a failing server trips a circuit breaker.
  • No library, no problem. Without libgascoigne (native) or the gascoigne CLI (proxy), proxy mode logs one warning per process and passes every result through.
  • Nothing is decorated unless your code asks. auto() is an explicit, reversible call, never an import side effect or an environment variable.

Pick a mode, pick a language

Four ways to hook in, the same six languages. Native and proxy are how the SDK reaches the engine; wrap and auto are how it meets your tools. Every example below is code from the demos.

Native. The engine runs inside your process as libgascoigne: no server, no gascoigne binary, no proxy URL. Same wrap calls as below.

Wrap. Pick tools one by one. Works with any provider and any framework.

Proxy. Point the LLM client at the gascoigne proxy: every tool result in every request is shortened, whatever produced it, with no tool code changes.

Auto. One explicit call decorates the place every tool call goes through, MCP tools included. Nothing is decorated unless your code asks.

Python · Native demos/python/langgraph/native.py

# 1. Start gascoigne in native mode. It raises if libgascoigne cannot be found.
gascoigne.init(agent="langgraph", mode="native")

# 2. Wrap the tool. The engine runs inside this process: no server, no CLI.
search_logs = gascoigne.wrap_tool(search_logs)

Select with GASCOIGNE_MODE=native|proxy or in code: init(mode="native"). The library merges its defaults, your user config and the settings you pass. The SDK itself stays thin and never carries the library; add the optional per-platform package, or point GASCOIGNE_LIB at a file.
