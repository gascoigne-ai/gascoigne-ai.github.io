Telemetry first

Agents read less. Nothing gets lost.

A Swiss Army knife for your coding agent's context. One small binary, a blade for every kind of output: it shrinks command output, tool results and web pages before they reach the model, and keeps every original one command away.

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest && gascoigne wrap claude

Claude Code starts with gascoigne for this run only. No config files are touched. Swap claude for codex, gemini, opencode or pi.

Open source, free to use

  • Apache License 2.0 for the CLI and all six SDKs.
  • Nothing to sign up for. No account, API key or cloud service is needed for the optimization itself: one static binary in pure Go, no cgo, and SDKs from GitHub releases.
  • Auditable. Every engine is public code, and the same input always gives the same output, so you can check what your agent was shown against the original.

How it works

gascoigne sits between your agent's tools and the model. Shell commands run through gascoigne exec, other MCP servers through gascoigne mcp-proxy, web pages through fetch, and the LLM API proxy trims what the agent's own tools return.

  1. Store. The original goes to a local ledger before anything is shortened.
  2. Fold. It recognizes the output's family and tool, then keeps what the agent acts on (failures, errors, diffs, summaries) and folds the rest. Short outputs pass through untouched.
  3. Retrieve. The shortened output ends with an id. gascoigne raw <id> or the MCP retrieve tool returns all of it, or only the lines that match.

What it does

Each panel loops from what the agent would get without gascoigne to what it gets with it.

Lossless by retrieval

Originals go to a local ledger before anything is shortened, and each shortened output ends with its id. When the agent needs a detail that was folded away, it asks for just that part, by grep, query or line range, instead of re-running the command.

Sources whose originals keep being fetched reach the agent whole next time, and output that would save less than its own hint costs is left as it is.

7,478 → 388 tokens, original one call away

MCP servers, trimmed

gascoigne mcp-proxy sits in front of any stdio MCP server. It shortens the server's text results and compacts tool schemas, keeping every constraint.

Tools you never call can load on request: the agent still sees their names and asks for one when a task needs it. A session's tool list never changes, so the prompt cache holds.

About 5,200 → 1,200 tokens of tool definitions

Browser pages, still clickable

Browser tools return the page as an accessibility tree, mostly menus. gascoigne keeps the head, the tail and whatever matches your query, and every kept ref stays, so the agent can still click what it sees.

Fetched HTML becomes markdown with the article kept and the chrome dropped: the Go release history page, 37k tokens of HTML, comes back at about 4k with a query.

6,569 → 2,601 tokens, every kept ref valid

Re-runs show only what changed

Agents re-run tests and builds after every edit. When the same command runs again in the session (within 20 minutes), runs of 4+ lines that one of the last 3 outputs already showed become one line, so only what changed is read again.

For test, build, task, pkg, log, search and vcs output

Big source files, safe to edit from

Source files only lose whole lines: comments and, in big files, long function bodies. Kept lines are byte-exact and every gap names the lines it stands for, so the agent can edit from what it read.

gascoigne show file.go:Func reads one function with its doc comment.

35,098 → 9,363 tokens on Go's net/http/server.go

Not an agent CLI? Use the SDK

The same shortening, inside your own agent app. The SDKs find the local gascoigne CLI, start its server and shorten tool results before your model reads them. No CLI on the machine means one warning and every result passes through unchanged; it never throws into your app. Apache-2.0, same as the CLI.

What it saves

It depends on what your agent runs. gascoigne keeps what an agent acts on — failures, diffs, errors, summaries — and folds the rest, so the more noise an output carries, the more it removes. Progress bars, passing tests and managedFields go almost entirely; a source diff or a short search result has little to cut. The darker the moon, the more your agent skipped.

One knife, sixteen blades

gascoigne carries a blade for each job and folds out the right one on its own. It recognizes output by family and tool (over 150 tools and formats), then hands it to the engine that knows what that output is for. Stack traces fold the same way in every family.

test
keeps failures and the summary, counts the passes. go, jest, vitest, bun, mocha, deno, pytest, cargo, rspec, maven, dotnet, JUnit XML, coverage
build
groups diagnostics by file and rule. go, tsc, eslint, golangci, ruff, mypy, rustc, gcc, clang, javac, dotnet, vite, webpack, docker, SARIF
pkg
drops progress and downloads, folds warnings by kind. npm, pnpm, yarn, bun, pip, uv, poetry, go mod, cargo, apt, dnf, brew
task
folds tasks that passed or came from cache. nx, turbo, make, just, gradle, compose, CI logs
vcs
shows edits as word diffs, folds lockfiles and moved blocks. git status, log, diff, blame and branch; gh
search
groups matches by file and merges identical lines. grep, rg, ag, git grep
fs
summarizes listings, drops comments and outlines big source files. ls, tree, find, du, df, source files
table
hoists constant columns, keeps unhealthy rows. ps, ss, lsof, top, systemctl, docker, any aligned or boxed table
data
compacts JSON and YAML, samples repeated records. JSON, NDJSON, YAML, CSV, XML, TOML lockfiles, Jupyter notebooks
log
folds lines into templates with counts, keeps errors and outliers. app, journald, syslog, docker, kubectl, access logs, CloudWatch, GCP, Azure
doc
drops badges and tables of contents, keeps whole sections. markdown, rst, man, --help
web
keeps the article, drops menus and chrome. HTML to markdown, HTTP responses, browser accessibility snapshots
db
prunes EXPLAIN to its costly nodes, results as tables. psql, mysql, sqlite, EXPLAIN, redis, mongosh, migrations
k8s
prunes managedFields and defaults, keeps unhealthy items. kubectl, helm
infra
folds refresh and progress, keeps what a plan changes. terraform, tofu, pulumi, ansible, cdk
cloud
strips pagination tokens, metadata and etags. aws, gcloud, az

Experimental, off by default

Four features that are not stable yet. Each stays off until you turn it on with gascoigne setup -experimental, which asks about each one with an example and its impact.

prose
A small local language model, on CUDA, CoreML or the CPU with no Python, drops low-value words from long paragraphs. Numbers, paths, flags and code stay; tables, lists and command output are left alone. Lossy, about 8–10% fewer tokens on prose-heavy text, and the original is one gascoigne raw away. See it work.
prompts
Lists the instruction text your agents send with every request and prices it.
learn
Proposes instruction lines from habits that cost context, such as commands run again for output that was already shortened.
continuity
After a compaction or resume, Claude gets a short snapshot: its last request, open tasks, edited files and failed commands.

Standing on good ideas

gascoigne takes inspiration and uplifts techniques from projects that showed what agents waste and how to win it back. Each is worth a look on its own.

  • rtk

    Filtering command output through an agent hook, and a gain report of what it saved.

  • Headroom

    Reversible compression: originals kept locally for the model to retrieve, and a proxy in front of the LLM API.

  • context-mode

    Keeping large tool output out of the context window, with a local index the agent can search instead.

  • caveman

    Tokens the agent writes count too: terse replies, technical detail intact.

Install

With Go 1.27+

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

The binary lands in $(go env GOPATH)/bin.

Prebuilt binary: Linux, macOS

v=$(curl -fsSLI -o /dev/null -w '%{url_effective}' https://github.com/gascoigne-ai/gascoigne-cli/releases/latest); v=${v##*/v}; os=$(uname -s | tr A-Z a-z); arch=$(uname -m | sed 's/x86_64/amd64/;s/aarch64/arm64/'); f=gascoigne_${v}_${os}_${arch}.tar.gz; b=https://github.com/gascoigne-ai/gascoigne-cli/releases/download/v$v; curl -fsSLO $b/$f -O $b/checksums.txt && grep " $f\$" checksums.txt | { sha256sum -c - || shasum -a 256 -c -; } && tar xzf $f && mkdir -p ~/.local/bin && cp ${f%.tar.gz}/gascoigne ~/.local/bin/

Takes the latest release for your system, checks it against checksums.txt and copies it to ~/.local/bin. The binary is not notarized: on macOS run xattr -d com.apple.quarantine ~/.local/bin/gascoigne

Prebuilt binary: Windows

$v=(irm https://api.github.com/repos/gascoigne-ai/gascoigne-cli/releases/latest).tag_name.TrimStart('v'); $a=if($env:PROCESSOR_ARCHITECTURE -eq 'ARM64'){'arm64'}else{'amd64'}; $f="gascoigne_${v}_windows_$a.zip"; $b="https://github.com/gascoigne-ai/gascoigne-cli/releases/download/v$v"; iwr "$b/$f" -OutFile $f; if(-not ((irm "$b/checksums.txt") -match ((Get-FileHash $f).Hash.ToLower()+' '+$f))){throw 'checksum mismatch'}; Expand-Archive $f . -Force; ni -Force -ItemType Directory $env:LOCALAPPDATA\gascoigne | Out-Null; cp "$($f -replace '\.zip$')\gascoigne.exe" $env:LOCALAPPDATA\gascoigne\

PowerShell. Verifies the checksum and copies gascoigne.exe to %LOCALAPPDATA%\gascoigne; add that folder to PATH. SmartScreen may ask to confirm the first run. All archives: Releases.

From a checkout

git clone https://github.com/gascoigne-ai/gascoigne-cli && cd gascoigne-cli && make install

Installs to ~/.local/bin; set PREFIX for elsewhere.

Remove it

gascoigne uninstall

Takes gascoigne out of your agents' configs, stops the server and deletes the ledger, config, caches and the binary. It lists everything and asks first.

One static binary in pure Go. The background server starts itself when needed and exits after 30 minutes idle.
