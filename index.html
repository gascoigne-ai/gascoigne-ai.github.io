gascoigne
Install Savings Docs GitHub

Agents read less. Nothing gets lost.

A Swiss Army knife for your coding agent's context. One small binary, a blade for every kind of output: it shrinks command output, tool results and web pages before they reach the model, and keeps every original one command away.

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest && gascoigne wrap claude

Claude Code starts with gascoigne for this run only. No config files are touched. Swap claude for codex, gemini, opencode or pi.

The original is one command away

Every original goes to a local ledger before anything is shortened, and each shortened output ends with its id. When the agent needs a detail that was folded away, it asks for just that part instead of re-running the command.

$ gascoigne raw 17415a92 -grep 'goroutine 7[0-9] ' -C 1
95-
96:goroutine 70 [chan receive, 9 minutes]:
117-example.com/shop/sync.(*worker).loop(0xc00020a000)
…

On a re-run after the fix, failures already seen in the session become one line: [↑ 5 lines as in the previous run, from "--- FAIL: TestParse"].

What it saves

Agents burn context on progress bars, passing tests, managedFields, pagination tokens and license boilerplate. gascoigne knows what each kind of output is for, keeps what an agent acts on — failures, diffs, errors, summaries — and folds the rest. The darker the moon, the more your agent skipped.

Watch it work

gascoigne dashboard opens a live view in your browser: savings per day, command and optimizer, every run as it happens, and any run's original side by side with what the agent read. Its moon shows your savings rate.

One knife, sixteen blades

Like a Swiss Army knife, gascoigne carries a blade for each job and folds out the right one on its own. Output is recognized by family and tool, more than 110 of them, and shaped by the engine that knows what that output is for. Stack traces fold the same way in every family.

test
keeps failures and the summary, counts the passes. go, jest, vitest, bun, mocha, deno, pytest, cargo, rspec, maven, dotnet, JUnit XML, coverage
build
groups diagnostics by file and rule. go, tsc, eslint, golangci, ruff, mypy, rustc, gcc, clang, javac, dotnet, vite, webpack, docker, SARIF
pkg
drops progress and downloads, folds warnings by kind. npm, pnpm, yarn, bun, pip, uv, poetry, go mod, cargo, apt, dnf, brew
task
folds tasks that passed or came from cache. nx, turbo, make, just, gradle, compose, CI logs
vcs
shows edits as word diffs, folds lockfiles and moved blocks. git status, log, diff, blame and branch; gh
search
groups matches by file and merges identical lines. grep, rg, ag, git grep
fs
summarizes listings, drops comments and outlines big source files. ls, tree, find, du, df, source files
table
hoists constant columns, keeps unhealthy rows. ps, ss, lsof, top, systemctl, docker, any aligned or boxed table
data
compacts JSON and YAML, samples repeated records. JSON, NDJSON, YAML, CSV, XML, TOML lockfiles, Jupyter notebooks
log
folds lines into templates with counts, keeps errors and outliers. app, journald, syslog, docker, kubectl, access logs, CloudWatch, GCP, Azure
doc
drops badges and tables of contents, keeps whole sections. markdown, rst, man, --help
web
keeps the article, drops menus and chrome. HTML to markdown, HTTP responses, browser accessibility snapshots
db
prunes EXPLAIN to its costly nodes, results as tables. psql, mysql, sqlite, EXPLAIN, redis, mongosh, migrations
k8s
prunes managedFields and defaults, keeps unhealthy items. kubectl, helm
infra
folds refresh and progress, keeps what a plan changes. terraform, tofu, pulumi, ansible, cdk
cloud
strips pagination tokens, metadata and etags. aws, gcloud, az

What you can rely on

Lossless by retrieval
Originals are stored first and every shortened output carries its raw id. Output that would save less than its own hint costs is left as it is.
Deterministic
Same input, same output, so prompt caches stay warm.
Safe to edit from
Source files only lose whole lines: comments and outlined bodies. Kept lines are byte-exact and every gap names the lines it stands for, like // … comments L12-30.
Self-correcting
When agents keep fetching a source's originals, that source is passed through next time.
Local
The ledger and dashboard stay on your machine. Nothing is sent anywhere.

Standing on good ideas

gascoigne borrows from projects that showed what agents waste and how to win it back. Each is worth a look on its own.

  • rtk

    Filtering command output through an agent hook, and a gain report of what it saved.

  • Headroom

    Reversible compression: originals kept locally for the model to retrieve, and a proxy in front of the LLM API.

  • context-mode

    Keeping large tool output out of the context window, with a local index the agent can search instead.

  • caveman

    Tokens the agent writes count too: terse replies, technical detail intact.

Install

With Go 1.27+

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

The binary lands in $(go env GOPATH)/bin.

From a checkout

git clone https://github.com/gascoigne-ai/gascoigne-cli && cd gascoigne-cli && make install

Installs to ~/.local/bin; set PREFIX for elsewhere.

Remove it

gascoigne uninstall

Takes gascoigne out of your agents' configs, stops the server and deletes the ledger, config, caches and the binary. It lists everything and asks first.

One static binary in pure Go. The background server starts itself when needed and exits after 30 minutes idle.
