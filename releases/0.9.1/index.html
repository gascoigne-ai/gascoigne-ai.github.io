gascoigne 0.9.1 A crash fixed in the hook.

The hook panicked on gh pr checks and on any other tab separated table whose rows differ in length. It now pads short rows. The SDKs move to 0.9.1 with it.

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Starting fresh? Install it first. Coming from 0.8.0: what 0.9.0 added.

What's new

No more crash on gh pr checks

What you get: the hook works on every table again. In 0.9.0 it failed with index out of range when a table's rows had different lengths, which gh pr checks produces. Short rows are now padded, so your agent receives the shortened table instead of an error.

SDKs 0.9.1

What you get: a working release of every SDK (Python, TypeScript, Go, Java, .NET, Rust) and the native library, built against this CLI. New: native demos for every Python and TypeScript framework and Spring AI, and a README that starts with a one-minute try-it that needs no API key. See the SDK page.

Upgrade

1. Install the new version

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Or download an archive from the release. The background server notices the new binary and restarts itself.

2. Nothing else to do

Nothing is migrated or removed, and no defaults change.
