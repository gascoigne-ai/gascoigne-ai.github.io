gascoigne 0.12.0 The last minor before GA.

Compound shell lines and git history commands get shorter, auto mode needs no retries, and the ledger records how a command ended. The SDKs move to 0.12.0 with it.

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Starting fresh? Install it first. Coming from 0.11.0: what 0.11.0 added.

What's new

Shorter output from compound lines and git history

What you get: make && go test ./...; git status now shortens each plain command in the line, and leaves redirects and substitutions alone. git merge, rebase, cherry-pick, commit, checkout and stash pop fold stat bars and runs of created or deleted files; conflicts, errors and markers stay. A second ps or ss in the same session becomes a pointer to the first. The hooks change, so they are re-registered after you upgrade.

Auto mode works without retries

What you get: Claude Code's auto mode reviews the command the model wrote, so a rewritten command was denied as changed after review and every shell call needed a retry. The hook now approves its own rewrite in auto mode; other modes keep their prompts.

A ledger that knows how a command ended

What you get: each exec event stores the exit code, the run time and the working directory. gascoigne gain -pipeline exec,hook filters by pipeline, and -by pipeline and -by type group by pipeline or detected type. Hook events never see the command end, so they stay unknown.

Steadier servers, typed SDKs

What you get: a cancelled command no longer starts or keeps child processes, a hung GPU probe or download times out, and a long-running server no longer grows without bound. The Python, TypeScript and Rust SDKs decode the server's answers once into typed models, and Python and Java stop at once on a protocol mismatch. See the SDK page.

Upgrade

1. Install the new version

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Or download an archive from the release. The background server notices the new binary and restarts itself.

2. Move the SDK too

If you use an SDK, update it to 0.12.0 together with the CLI. An SDK now rejects a server answer with a missing or wrongly typed field: optimize falls back to the original and ledger reads return an empty list.
