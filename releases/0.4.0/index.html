gascoigne 0.4.0 Binaries for every system.

Every release now carries ready-made archives for Linux, macOS and Windows (amd64 and arm64) and a checksum file. No Go toolchain needed.

Install commands that check the checksum are in the install section. Already using gascoigne? Run the same command again, then gascoigne upgrade.

What's new

Prebuilt binaries

Six archives and checksums.txt on each GitHub release. The binaries are not signed or notarized: on macOS run xattr -d com.apple.quarantine on the file once; Windows SmartScreen may ask to confirm.

Where context costs money

gascoigne context and a dashboard page show what conversation size and cache rewrites cost, and what compacting saves.

A weekly MCP review

A browser page shows which MCP servers you use, where each is configured and how to switch it off.
