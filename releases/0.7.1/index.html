gascoigne 0.7.1 See what it costs, hear about updates sooner.

The dashboard gets a costs page, new releases are noticed within 15 minutes, and make eval ends with a summary you can read.

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Starting fresh? Install it first. Coming from 0.7.0: more tools, less noise.

What's new

A costs page and easier periods

The dashboard has a costs page, long periods are easier to read, and sessions can be filtered.

Update notices within 15 minutes

The release notice reads latest.json every 15 minutes, from agent hooks and dashboard instead of the background server. A prompt, not only a session start, opens the page of a newer release, and the page is retried until it opens.

A readable eval

make eval prints a banner per suite, savings bars and a final summary. The script also runs on the bash 3.2 that ships with macOS.

Fixes

  • The fake MCP authorize endpoint used in tests redirects only to loopback, to the fixed callback path.

Upgrade

1. Install the new version

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Or download an archive from the release. The background server notices the new binary and restarts itself.

2. Look at your costs

gascoigne dashboard

Nothing is migrated or removed. The costs page is in the dashboard (gascoigne dashboard).
