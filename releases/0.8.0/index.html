1 November 2026

gascoigne 0.8.0 Fewer tokens from the session itself.

Screenshots are downscaled in the Claude hook, piped commands are optimized, budgets tighten when the context grows large, and 30 new dialects cover more tools.

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Starting fresh? Install it first. Coming from 0.7.2: quoted env assignments in the hook.

What's new

Session-level savings

  • Image Reads above max_image_pixels are downscaled in the Claude hook. The result keeps its shape and the original stays in the ledger. The default is now 600000 pixels (it was off); set it to 0 to keep images whole.
  • Pipelines that end in grep, jq, sort, wc and similar are optimized, and the exit status of the whole pipeline is kept.
  • A context-size note on prompt submit above a threshold ($GASCOIGNE_CONTEXT_NUDGE, off to disable; nothing is forced), and tighter truncate, log and grep budgets once the context is large.
  • MCP results from the hook carry the call's url and query, as in the LLM proxy, so fetch-like results are typed and sampled for the query. fetch answers a repeated URL with a pointer or a diff, and mcp-proxy can trim tool descriptions.
  • opencode gets a tool.execute.after hook for what the rewrite missed.

A source that failed once is not skipped for good

The history filter used to bypass a source after one failure, permanently. It now needs 2 failures (3 for fetch URLs) within failure_ttl, 24 hours by default.

Project config

A .gascoigne.yaml, searched from the working directory up to the git root, lays over your user config for exec and the hooks. Each repo gets its own warm pipeline.

New dialects

  • Node, Deno and Bun stack frames; JSON diagnostics from cargo, eslint, ruff, golangci-lint, mypy and pylint.
  • kubectl apply|delete|rollout status, dmesg, docker pull|push, terraform init, state list and validate.
  • Text lockfiles (pnpm, pubspec, mix, Podfile, Package.resolved, bun) and dependency trees (npm ls, pnpm why, cargo tree, pipdeptree, uv tree, gradle and more).
  • Coverage tables, git reflog, stash list, tag, remote -v and a bare diff --stat, web search results, free, vmstat, findmnt, pip list, pacman -Q, the make eval table.
  • truncate keeps lines after each error, and find/tree folds keep directory names.

Reports

  • gain shows rerequested and wasted tokens per dialect, optimizer and command; raw prints a size header for large originals.
  • The dashboard has costs and context pages with charts, one model table and a detail row per session; install -window sets Claude's auto-compact window.

Upgrade

1. Install the new version

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Or download an archive from the release. The background server notices the new binary and restarts itself.

2. Nothing else to do

Nothing is migrated or removed. Screenshots above 600000 pixels are downscaled from now on; set max_image_pixels: 0 under receivers.httpproxy to turn that off.
