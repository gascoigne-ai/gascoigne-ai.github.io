gascoigne 0.8.0 Fewer tokens from the session itself.

Screenshots are downscaled in the Claude hook, piped commands are optimized, budgets tighten when the context grows large, and 30 new dialects cover more tools.

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Starting fresh? Install it first. Coming from 0.7.2: quoted env assignments in the hook.

What's new

Fewer tokens from the session itself

  • Screenshots cost less. Large images the agent reads are scaled down before the model sees them (above 600000 pixels; set max_image_pixels: 0 to keep them whole). The original stays in the ledger.
  • Piped commands are shortened too. cmd | grep, jq, sort, wc and similar no longer escape optimization, and the exit status of the whole pipeline is kept.
  • Big contexts get tighter output. When the conversation grows large, results shrink more, and you get a short note about the context size ($GASCOIGNE_CONTEXT_NUDGE=off turns it off). Nothing is forced.
  • MCP results are smarter. Fetch-like results are shortened for the question that was asked, a repeated URL gets a pointer or a diff, and mcp-proxy can trim long tool descriptions.
  • opencode gets a hook for what the rewrite missed.

One bad run no longer blocks a source for good

What you get: fewer sources silently left unoptimized. A source is skipped only after 2 failures (3 for fetch URLs) within 24 hours, instead of after one failure, forever.

Per-project settings

What you get: different rules per repo. A .gascoigne.yaml, found from the working directory up to the git root, lays over your user config for exec and the hooks.

30 more kinds of output understood

What you get: shorter results from more of the tools you run.

  • Stack traces from Node, Deno and Bun; JSON diagnostics from cargo, eslint, ruff, golangci-lint, mypy and pylint.
  • kubectl apply|delete|rollout status, dmesg, docker pull|push, terraform init, state list and validate.
  • Lockfiles and dependency trees (npm ls, cargo tree, uv tree, gradle and more), coverage tables, git reflog, stash list and tag, web search results, free, vmstat, pip list, pacman -Q.
  • truncate keeps the lines after each error, and find and tree keep directory names.

See where the money goes

  • Dashboard: new costs and context pages with charts, one model table and a detail row per session. install -window sets Claude's auto-compact window.
  • gain shows how many tokens were re-requested and wasted, per tool, optimizer and command; raw prints a size header for large originals.

Upgrade

1. Install the new version

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Or download an archive from the release. The background server notices the new binary and restarts itself.

2. Nothing else to do

Nothing is migrated or removed. Screenshots above 600000 pixels are downscaled from now on; set max_image_pixels: 0 under receivers.httpproxy to turn that off.
