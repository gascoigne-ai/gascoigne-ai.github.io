gascoigne 0.6.1 Savings you can believe.

When an agent reads an optimized result and then asks for the original, the optimization did not help: it cost the result and the original. gascoigne now records that run as rerequested, subtracts it from your savings and charts optimizing against rerequesting on the dashboard.

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Starting fresh? Install it first. Coming from 0.5: prose model choice.

What's new

Rerequested runs are not savings

A run is stored as rerequested instead of optimized when the agent fetches its original in full (gascoigne raw, MCP retrieve) or runs the same source raw right after. It counts as the agent read it: the optimized result plus the original, so gain, the dashboard totals and the cost section subtract it. Runs recorded before are converted once, the first time the ledger starts.

  • Optimized: the agent was happy with the shorter version.
  • Unchanged and Bypassed: untouched, no effect on savings.
  • Rerequested: a token penalty. Raw: the agent asked for the original at once.
  • Failed: optimizer errors, as before.

Fetching only part of an original (-grep, -lines) is not tracked yet, so the real rerequest rate is probably a little higher than shown.

Optimizing vs rerequesting, on the dashboard

A new chart shows, per day, the tokens saved by optimized runs against the tokens read twice because of rerequests, with net saved and the rerequest rate. The run feed filters by Optimized, Bypassed, Unchanged, Rerequested, Raw and Failed, and Bypassed has its own color.

Retention you can set

Originals now stay 30 days (ledger.raw_ttl, was 24 hours). Runs, API usage and failure history stay a year (ledger.events_ttl, new, were forever), and the MCP tool stats a year (ledger.stats_ttl, was two weeks). Set any of them to 0 to keep it forever.

Fixes

  • gascoigne tokens with no file on a terminal waited for input forever; it now tells you what to do.
  • gascoigne tokens no longer stalls on long text without spaces, and its downloads time out after 30 seconds.
  • Groups in gain are ordered by net savings, not gross.
  • Blank lines in git branch output no longer crash the git optimizer.

Upgrade

1. Install the new version

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Or download an archive from the release. The background server notices the new binary and restarts itself.

2. Open the dashboard

gascoigne dashboard

Your history is converted on the first start: runs the agent re-asked about show as rerequested, and your savings total may drop a little. Nothing is lost.
