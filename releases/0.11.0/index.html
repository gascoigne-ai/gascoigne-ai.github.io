gascoigne 0.11.0 A safer pricing setup.

The setup page can no longer set what reads files, reaches the network or runs a program, and the SDKs count tokens only. The SDKs move to 0.11.0 with it.

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Starting fresh? Install it first. Coming from 0.10.0: what 0.10.0 added.

What's new

A safer pricing setup

What you get: a price file, a price URL, a header variable and a translating command are set only in a terminal, with gascoigne pricing set. The setup page has no login, and these read files, reach the network or run programs, so it now saves only billing, the refresh interval and your own prices, and shows which sources are in use. The sources are also checked harder: a regular file of at most 1 MiB, an http(s) address without credentials, at most 3 redirects and never from https to http, and a command that resolves on PATH.

The SDK counts tokens

What you get: the costs call and the pricing option of the 0.10.0 SDKs are gone. Every SDK keeps totals and runs (tokens saved, recent runs) and the in-memory ledger. Prices and billing stay in the gascoigne CLI. See the SDK page.

Upgrade

1. Install the new version

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Or download an archive from the release. The background server notices the new binary and restarts itself.

2. Move the SDK too

If you use an SDK, update it to 0.11.0 together with the CLI: the native library is now ABI 3 and refuses a 0.10.0 SDK. Code that called costs or passed pricing must drop them. If you set a price file, URL or command from the setup page, set it again with gascoigne pricing set.
