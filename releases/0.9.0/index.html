gascoigne 0.9.0 Smarter folding, and an engine you can embed.

Shorter logs, fewer wasted round trips, MCP savings applied for you, and SDKs that run inside your app with no server.

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Starting fresh? Install it first. Coming from 0.8.0: session-level savings.

What's new

The SDKs can run without a server

What you get: add gascoigne to your own agent app without installing anything next to it. Python, TypeScript, Go, Java, .NET and Rust can load libgascoigne and do the work inside your process. It is simpler to deploy and quicker per call. The old way, through the local server, still works. See the SDK page for examples.

Logs shrink further

  • Similar lines fold together. Lines that differ only in a host or a user name become one line with a count, so long logs get much shorter.
  • The important line stays. One status=503 among hundreds of status=200 lines is kept, and spikes are no longer averaged away.
  • You see where it happened. A repeated message that clusters says so, for example mostly lines 661–687.
  • Search results are more varied. When the agent asks about something, near-identical matches no longer fill the answer.

Sources the agent keeps re-reading

What you get: fewer wasted round trips. If the agent fetches the whole original after a short result, that source is shortened less next time rather than being skipped for good. A whole kind of output (logs, tests, …) does the same when this keeps happening, and sources recover as they do well. gain -refetch shows how often it happens.

MCP review fixes things for you

What you get: smaller requests. The review sorts servers and tools by use, lists tools nobody called this week and can set them to load on request, with one button or gascoigne mcp-review -optimize. It also suggests what to change in your agent's own config. Nothing is removed.

Smaller things

  • Try settings safely. replay -set compares two settings on the same transcripts.
  • Cache advice. context tells you when a 1-hour cache would save money after long pauses.
  • See what a pipeline does. Each pipeline lists its active optimizers under optimizers:.
  • Setup after an upgrade. The dashboard opens the setup page once so you can finish updating.

Upgrade

1. Install the new version

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Or download an archive from the release. The background server notices the new binary and restarts itself.

2. Check two defaults

history.max_failures is now 2 (was 1): the first failure gets the gentle route, the second bypasses. Set it to 1 for the old behavior. The passthrough optimizer is gone; use optimizers: [] to leave an output as it is.
