gascoigne 0.9.0 Smarter folding, and an engine you can embed.

Logs fold by Drain templates, sources the agent keeps fetching raw get a gentler route, mcp-review applies the savings it finds, and every SDK can run the engine inside your own process.

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Starting fresh? Install it first. Coming from 0.8.0: session-level savings.

What's new

SDK 0.9.0: native mode

The SDKs now share the CLI's version number. Every one of them (Python, TypeScript, Go, Java, .NET, Rust) can load libgascoigne and run the engine in the application process: no server, no gascoigne binary on the PATH. The Go CLI exposes the same pipeline as a public inproc package. See the SDK page for examples.

Log folding

  • miner: drain folds lines that differ in a few words (host, user) by Drain template clusters; warnings and errors never merge.
  • outliers: mad keeps spikes the 10x median rule misses, bursts says where a template's repeats cluster (mostly lines 661–687), and rarity keeps the entries standing for the fewest lines.
  • Codes stay apart: one status=503 among status=200 lines is no longer folded into them. passes picks the stages that run before templating.
  • truncate can pick query lines by maximal marginal relevance (query_diverse), so near-identical matches do not fill the budget.

Sources fetched raw get a gentler route

When the agent fetches the whole original after an optimized result, that source takes a gentle route (the same chain, less aggressive) before it is bypassed. A whole family goes gentle when too many of its results are fetched raw, and optimized runs forgive failures. gain -refetch shows how often each family was fetched raw afterwards.

MCP review applies what it finds

  • Servers and tools are sorted by usage, with suggestions: tools not called in 7 days to load on request, and advice for the agent's own config (switch an unused server off, max_tools, trim_descriptions).
  • The Auto-optimize button, or gascoigne mcp-review -optimize, adds the suggested lazy tools from the next session. Nothing is removed.

More

  • replay -set compares settings on the same transcripts; pipelines list their active optimizers under optimizers:.
  • Advice on 1-hour cache pauses in context; prompts flags skills and subagents no transcript shows.
  • The dashboard opens the setup page once after an upgrade, and its Change button opens it with a token.

Upgrade

1. Install the new version

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Or download an archive from the release. The background server notices the new binary and restarts itself.

2. Check two defaults

history.max_failures is now 2 (was 1): the first failure gets the gentle route, the second bypasses. Set it to 1 for the old behavior. The passthrough optimizer is gone; use optimizers: [] to leave an output as it is.
