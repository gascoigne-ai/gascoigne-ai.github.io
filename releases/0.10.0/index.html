gascoigne 0.10.0 Your own optimizer, your own prices.

Run a program of yours as an optimizer, let gascoigne tell a flat plan from an API key, and choose whether your agent calls MCP itself. The SDKs move to 0.10.0 with it.

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Starting fresh? Install it first. Coming from 0.9.1: what 0.9.1 fixed.

What's new

Your own optimizer

What you get: a script or binary of yours shortens the output of the commands you route to it, with no Go and no fork. It speaks text, JSON or RPC. The original stays retrievable through [raw:<id>], a failure returns the original output, and it is read from your own config only, never from a repository's. See the contract.

Plan or API, found out for you

What you get: gascoigne looks at how each agent is signed in and leaves agents on a flat plan out of the dollar figures; the Context page shows requests and context sizes for them instead. gascoigne pricing sets prices of your own, from a price sheet or a URL that refreshes daily.

Automatic or manual MCP

What you get: install -mcp manual stops the hooks rewriting results, so your agent calls gascoigne's tools itself. Automatic stays the default.

Shorter results and guide

What you get: shortened output ends with [raw:<id>] instead of a hint with token counts, and the usage guide is short only.

SDKs 0.10.0

What you get: every SDK reads totals, runs and costs of the savings it produced, and can keep its ledger in memory. See the SDK page.

Upgrade

1. Install the new version

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Or download an archive from the release. The background server notices the new binary and restarts itself.

2. Check two defaults

Billing is now detected per agent (billing: auto), so agents on a flat plan lose their dollar figures. A saved full usage guide reads as short. Nothing else is migrated.
