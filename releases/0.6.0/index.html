gascoigne 0.6.0 Pick the model that reads your prose.

Prose compression now comes with two local models, and setup asks which one you want, downloads it with a progress bar and checks its files. The background server also speaks an API the agent framework SDKs use. Still an experiment, off until you say yes.

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest && gascoigne setup -experimental

Starting fresh? Install it first. Coming from 0.4: prose compression and prebuilt binaries.

What's new

Two prose models, one question in setup

gascoigne setup now asks which model the prose experiment runs, and with prose on it downloads the one you pick and checks its files. Change your mind later with optimizers.prose.model or gascoigne prose install -name; the ONNX Runtime is shared, so the second model only adds its own files.

  • kompress-v2-base, 274 MB: trained on general prose. It drops articles and fillers and keeps the meaning of the test fixtures at the default threshold. This is the default, now as an int8 graph: less than half the earlier download, the same savings, identical output on CPU and CUDA.
  • ctxprune-small, 563 MB: trained on tool output, logs, code and web text. About three times faster on the CPU, and at the same threshold it keeps fewer words on prose.

Each model lives in a directory named after it, so files and checksums never mix. The guide has the comparison and how to try both on your own text.

A progress bar for the download

Models are hundreds of megabytes. In a terminal, prose install and setup now draw a bar with percent and megabytes instead of staying silent. Pipes, CI and the background server keep the plain output.

  [###############---------------]  50%  137/274 MB

An API for agent framework SDKs

The background server serves /sdk/v1, the API that the SDKs use to shorten tool results inside agent frameworks.

Smaller things

  • A minimal Alpine Docker image: a static build and a non-root user.
  • The dashboard shows live status on every page, explains the prose step in plain words and uses plainer labels in run details.
  • Maven errors keep their symbol and location lines, and a repeated finding lists every line.
  • Unpacking the ONNX Runtime archive cannot write outside its directory.

Upgrade

1. Install the new version

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Or download an archive from the release. The background server notices the new binary and restarts itself.

2. Bring your setup current

gascoigne upgrade

Your config.yaml moves onto the new template, settings kept.

3. Download the model again if you use prose

gascoigne setup -experimental

Models now install into directories of their own, so a 0.5.0 download is not found. Setup asks which model you want and fetches it.
