gascoigne 0.7.0 More tools, less noise.

Compiler, test runner and package manager output from dozens more tools is now recognised and shortened, gain prints a short report you can shape, and the ledger keeps daily totals of runs older than a year instead of losing them.

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Starting fresh? Install it first. Coming from 0.6: savings net of rerequests.

What's new

A gain report you can shape

Plain gain now prints the essentials: totals, the last 7 days, agents, commands and a warning when sources went bad, with tables cut at 10 rows. gain -full prints every section as before.

  • -show and -hide pick sections by name; -top, -sort and -min-tokens shape the tables.
  • -csv exports a -by grouping or the failing sources as plain numbers.
  • Failing sources show when they last failed ("2d ago"), and the header prices the savings when a cost estimate exists.

History that outlives a year

Runs older than ledger.events_ttl (still a year) used to be deleted. They are now added to daily totals first, per day, agent, model, command, route, outcome and optimizer, so gain -by month keeps counting them. ledger.rollup_ttl defaults to 0s, which keeps the totals forever. Session and reason groupings only cover runs still stored.

Many more tools

  • Build: CMake, Ninja, Meson, Bazel, clang-tidy, cppcheck, MSVC, dmd, sbt, Swift, Zig, Kotlin, GHC, Dart, rubocop, pylint and formatters. C++ template and include chains keep their ends; a linker's undefined references become one list.
  • Test: ctest, GoogleTest, Catch2, sbt, dub, PHPUnit, swift test, mix, minitest, unittest, TAP, Playwright, Cypress, Karma, flutter, cabal and stack. Passes are counted, failures stay.
  • Packages: Composer, Bundler, mix, pub, SwiftPM, NuGet, conda, deno, Nix, Flatpak, snap and mvn dependency:*; text lockfiles shrink to name@version lists.
  • Stack traces fold runtime and framework frames of the JVM, Python, Rust, Ruby, .NET, PHP, gdb/lldb and sanitizers into one count.
  • Source outlines for Ruby, Elixir, Lua, Haskell, OCaml, Clojure, Perl, R, PowerShell and more, and a rewritten outline for Rust, C++, Scala and D.

Fixes

  • Rust lifetimes, nested block comments and raw strings no longer break the source outline.
  • The release notice checks hourly, so a new release is seen the same day.
  • No more panics on a bare git commit line or dense with a tail of 0; debug log levels match exactly; output after a cached nx task is kept.

Upgrade

1. Install the new version

go install github.com/gascoigne-ai/gascoigne-cli/cmd/gascoigne@latest

Or download an archive from the release. The background server notices the new binary and restarts itself.

2. Look at your savings

gascoigne gain

The report is shorter now; gain -full shows everything. Two tables for the daily totals are created on the first start. Nothing is migrated or removed.
